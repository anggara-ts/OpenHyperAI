Hero review, all 127 heroes

Every hero in Valve's datafeed hero list was checked against the current patch: ability names, damage types, cast types, special-value keys, Shard and Scepter texts, talents, skill builds and item builds. Obvious gaps were fixed directly in the hero files.

commit 9a2d7e6 build 2026.11.16-086 map 0.7.41 - 2026/11/16 8 parallel reviewers

What kinds of bugs were found

  • Special-value keys that no longer existThe game returns 0 for a missing key, so kill checks, ranges and radii silently never worked. Examples: Tiny Avalanche, Zeus Lightning Bolt, Lina Dragon Slave, Lion Earth Spike, Enigma Malefice, Jakiro Macropyre, Tidehunter Anchor Smash, Omniknight Martyr, Witch Doctor Cask bounce, Gyrocopter rockets.
  • Wrong damage typesKill checks used magical for physical spells or the reverse (Slardar, Spectre, Ursa, Silencer, Grimstroke, Primal Beast, Monkey King, Kez, Riki, Lina Laguna with Scepter).
  • Abilities that were never castNever called, gated on the wrong variable or fetched by an old name: Lifestealer Infest, Clinkz Burning Army, Jakiro Liquid Ice, Tiny Tree Volley, Spirit Breaker Planar Pocket, Chen Zealot, Lone Druid Entangle, Shadow Demon Demonic Cleanse and more.
  • Wrong or empty targetsSpells aimed at nil, at the bot itself or at the wrong side (Chen Divine Favor on enemies, Silencer Glaives on nil, Night Stalker Void with a Scepter, Centaur Double Edge).
  • Skill and item buildsUltimates placed a level late or at an unlearnable level, an invalid item name (Tidehunter), support builds full of carry items (Kunkka, Snapfire), reversed sell pairs (Outworld Destroyer, Marci, Batrider), duplicate items, unused starting Circlets.
